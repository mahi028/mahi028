## 🚀 Featured Projects

### 🔬 [Photon](https://github.com/mahi028/Photon)
**AI-Powered Image Processing Sandbox**

An autonomous natural-language image processing studio where users can describe
image transformations in plain English and an LLM generates, executes, evaluates,
and self-corrects Python code in real time.

**Highlights**
- 💬 Conversational image processing using natural language
- 🤖 Autonomous code generation and execution loop
- 🔄 Automatic error analysis and self-correction
- 🖼️ RGB, RGBA, grayscale and float32 multispectral `.npy` support
- 📦 Batch image processing
- 📝 Built-in manual Python code editor
- 🔍 Visual versioning with comparisons and filmstrips
- 📁 Full-resolution ZIP export

**Focus:** LLMs • Computer Vision • Python • Code Generation • AI Agents

### ⚙️ [Mechanical Parts Detection](https://github.com/mahi028/Mechanical-Parts-Detection)
**Object Detection & Automated Counting**

Computer vision system for detecting and counting mechanical components in
CAD workspace images.

- Trained **YOLO11m** models using the Ultralytics framework
- Tuned augmentation, hyperparameters and learning schedules
- Developed IoU-based matching for detection/counting evaluation
- Optimized confidence thresholds using **F1-score analysis**
- Achieved ~**99.5% mAP** on validation data
- Achieved ~**99% counting accuracy** on the competition metric

**Focus:** PyTorch • YOLO • Object Detection • Computer Vision

### 🌱 [Plant Disease Classification](https://github.com/mahi028/Plant-Disease-Classification)
**Deep Learning Image Classification**

Deep learning system for multi-class plant disease classification.

- Designed a custom **ResNet-style CNN**
- Implemented residual blocks for improved feature learning
- Addressed class imbalance using augmentation and **weighted focal loss**
- Applied regularization strategies to improve generalization
- Achieved ~**97.7% test accuracy**

**Focus:** PyTorch • CNNs • ResNet • Classification • Imbalanced Learning
